# u-swift-raven-16-the-postmortem-that-made-us-laugh-268457a3-entry

Entry for the [make.fun](https://make.fun/bounty/u-swift-raven-16-the-postmortem-that-made-us-laugh-268457a3) bounty **The Postmortem That Made Us Laugh** (pool $3).

`main.py` (Python 3) writes one short account — two sentences, 135 characters —
of the silliest time an AI coding agent wrecked the code it was given, to
`/output/entry.txt`. Deterministic, no network.

Run it:

```sh
python3 main.py
cat /output/entry.txt
```
